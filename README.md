# kintai

個人用の勤怠管理Webアプリです。Slackへ貼り付ける出勤/退勤報告文をテンプレートベースで生成できます。

## セットアップ

```bash
npm install
npm run dev
```

- アプリ: `http://localhost:3000`
- SQLite DB: `./data/kintai.db`（初回アクセス時に自動作成）

## 主な機能

- 設定画面で出勤/退勤テンプレートを登録（タイトル + 箇条書き）
- 出勤画面で前回稼働日のTODOを含む報告文を生成しコピー
- 作業報告画面で作業/休憩/翌日TODOを保存
- 退勤前報告画面で本日の作業タイトルと時間を含む報告文を生成しコピー
